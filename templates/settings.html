Deployment Notes

How the panel works

  • Servers are stored as manual URIs in the database. No external JSON source is fetched.
  • Use /subscription/{id} for public subscription pages.
  • Use /api/* for tokenized integrations (pass token via Authorization: Bearer header or ?token=).
  • All subscription formats are supported: ?format=happ, ?format=base64, ?format=list, and more.
  • The profile header includes # announce: base64:... with the subscription description encoded in Base64.
